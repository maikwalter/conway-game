# conway-game

A Python implementation of Conway's Game of Life — a learning project in Python, algorithms and cellular automata.

## About

This project started as a programming exercise to refresh and deepen my Python skills.

The implementation uses a simple two-dimensional grid and separates the game logic, display and user interaction into individual functions.

## Features

- Randomly populated game boards
- Predefined patterns such as gliders and blinkers
- Conway's Game of Life rules
- Generation and population counter
- Pause / resume with `SPACE`
- Quit with `ESC`

## Requirements

- Python 3
- Pygame

## Status

Work in progress. The project is primarily a learning exercise.
